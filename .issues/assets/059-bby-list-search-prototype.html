Prototype notes. Full 28-field header in one horizontally-scrolling grid (the WPF completeness, restyled) — grouped headers, a sticky Status+Number identity column, sortable columns, and a toggleable per-column filter row (the WPF auto-filter, on demand). Codes render as compact chips (R=Document, A/O=And/Or); booleans as ✓/–; dates yyyyMMdd→yyyy-MM-dd, times HHMMSS→HH:mm. Export emits every field. A Details ▸ button sits in the sticky identity column — on demand it opens the SAP-style "Display Bonus Buy" modal (ticket 060: header + Buy→Get condition rows + grouping members), which the flat header grid does not show.
