# 722 — What would buying an equivalent OMS cost?

## Question

What would it cost, in money and time, to get what we already have by **buying** it?

Cover these cost lines:
- licence or subscription for a top-tier OMS (pricing model and published or analyst-reported
  ranges),
- system-integrator implementation cost and typical go-live time,
- the add-ons that a generic OMS would still need to match us: pharmacy, insurance (Nphies), SAP
  integration, aggregator connectors and a POS,
- yearly running cost.

The answer should include a cost table with a source and a confidence level for each figure.
Where vendors publish no price, use analyst or public-tender figures and label them as estimates.
Also give a short framing of **what our in-house build cost to reach the same coverage**, using
inputs the owner supplies (team size and months), so the CFO slide compares like with like.

Write it with `/research` to `docs/research/717-cost-of-buying.md`.
